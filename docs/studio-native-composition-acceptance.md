# Native authoring composition — bounded independent acceptance

## Accepted scope

The independent read-only review of the **private, single-operator, draft-only** native authoring composition reproduced no new concrete reachable security flaw. Parent verification matched all **152 frozen source/test/SDK metadata/probe path hashes**, every corresponding inert archive, and all **14 completion-manifest artifact hashes**. No frozen path drift was found before or after parent replay.

This accepts only the inspected native composition boundary. It is not acceptance of the newer working-source validation Worker, workspace durability/HTTP remediations, host identity or independent-human grants, real provider access, Docker runtime, deployment or public production.

## Actual verification

- Independent focused suite: **344 passed physical assertion records across 10 files**. Each selected case is already present in the historical full authoring report, checked with multiplicity-aware comparisons; these are not added to its total.
- Independent actual-installed-Anthropic-SDK fixture: **31 unique fake-fetch probes passed**. This exercised the actual root, SDK, capabilities, broker/loop, protected pipeline and real pure sub-app generator/browser parser. No live vendor requests or real credentials were used.
- Parent replayed those same 31 probe definitions against current unchanged source with a clean synthetic HOME/environment and the original remote-network guard. Only the output directory changed. All 31 passed, both syntax/execution commands exited 0, the guard recorded zero refused remote attempts, and the owned replay root was removed. This is reproduction of the same cases, not 31 additional independent probes.
- The review's original whole-project TypeScript retry exited 0. Its earlier unrelated in-flight UI typecheck failure, failed malformed-datasource fixture and initial guard lookup failure remain preserved as qualified harness/concurrency evidence, not application vulnerabilities.

Boundaries covered include sensitive input/skill refusals, exact reviewed skill context, stale credential/session and datasource grant changes across awaits, combined model-send counting, tool count and authority, protected step/gate preservation, real generator semantics, and retained admission while an abort-ignoring original SDK send remained pending. The latter kept a competing request at 429, rejected the late artifact, and released capacity only after original settlement.

## Budget qualification

The combined root bound is **six model sends per create request** (including preceding JSON classifier/metadata sends) and sixteen native tool calls. It is **not a unified token or financial cap**. The reviewed two-JSON/four-native sequence had `max_tokens` values `[16000, 16000, 4096, 4096, 4096, 4096]`. Native broker token/byte limits do not replace the existing JSON path's output limits. No hard spending guarantee is inferred.
