# Explicit working-source static validation — mounted integration

## Delivered

The existing **Saved sub-app** modal in the actual Studio entry now contains **Check working source**. It creates no new header/editor rows and performs no automatic check on mount, open or saved-source replacement.

The explicit gesture captures bounded applied working files, starts the real local module Web Worker, runs the existing seven static conformance checks and computes a Web Crypto SHA-256 fingerprint. The report shows fixed rule titles/positions and counts, not raw source snippets. It remains separate from immutable generated evidence and is never turned into a typecheck, evaluation, host grant or deployment approval.

Dirty/conflicted buffers are blocked until in-session Save. First typing invalidates a previous receipt even after revert. Round/scope/hide/cancel changes abort owned work and reject late results. Saving the same checked bytes retains only the same in-session receipt; explicit reopen restores exact source and original baseline, but does not automatically check it. Closing clears a receipt. Missing Worker refuses without a UI-thread checker fallback. Native cancellation/deadline cleanup is bounded by browser scheduling, not a hard real-time promise.
